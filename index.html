Foundation Forensics

ASCE Level B Evaluation · Independent Technical Documentation · Multi-Visit Monitoring

A single-file, offline-capable evaluation platform for independent residential foundation forensics — built around multi-visit time-series monitoring, sub-slab plumbing impact analysis, field-test evidence integration, and raw-data export for licensed Professional Engineer review.

Scope of practice This platform produces technical documentation. It renders no engineering opinion as to causation, structural load capacity, soils behavior, or code compliance; where a signed and sealed opinion is required, a licensed Texas Professional Engineer must review the data and issue that opinion under their own seal (Texas Occupations Code Ch. 1001; TBPE rules). It performs no repair or remediation, and it does not negotiate, adjust, or advocate any insurance claim — under the Texas Insurance Code only a licensed public adjuster or a licensed attorney may do so.

What it does

  • Relative elevation survey with live differential, deflection-ratio, and tilt calculation against published residential thresholds.
  • Plan-view rendering with discrete 0.25″ settlement bands and marching-squares iso-settlement contours.
  • Sub-slab plumbing impact analysis — per-segment slope against IPC Table 704.1 / IRC P3005.3 minimums, with a comparative joint-stress index derived from differential settlement, pipe material joint tolerance, and installation era.
  • Multi-visit time-series — initial, monitoring, and post-repair survey visits on one property, with movement rate in inches per month computed between any two visits.
  • Per-segment field-test evidence — CCTV stills, hydrostatic results, smoke test photos, and field notes bound to the specific sewer segment where they were observed.
  • Site geology from the USDA NRCS Soil Data Access service, or from an embedded regional series database when offline.
  • Raw-data export — elevation grid and plumbing segments as CSV for a licensed P.E. to review and seal independently.

Running it offline

Download foundation_forensics_v3.html and open it. There is no install, no account, no server, and no network dependency at runtime — the PDF engine is bundled into the file, so report generation works on a tablet with no signal. Web fonts load from the network when it is available and fall back to system fonts when it is not.
